# SF6 Buckler エクスポートツール - 使い方

## このツールでできること

ストリートファイター 6 の公式戦績サイト「Buckler's Boot Camp」から、あなたのランクマッチ戦績を自動で取得して CSV ファイルに保存します。

- 2 時間 30 分ごとに自動で戦績を取得
- Excel 等で開ける CSV 形式で保存
- 過去の戦績も自動で統合・重複削除

## 必要なもの

- Windows PC
- Node.js（バージョン 14 以降）
- SF6 の Buckler アカウント
- 自分の SID（プレイヤー ID）

## インストール

### 1. Node.js のインストール

[Node.js 公式サイト](https://nodejs.org/)からダウンロードしてインストールしてください。

確認方法：

```powershell
node --version
```

バージョンが表示されれば OK です。

### 2. ツールのインストール

PowerShell またはコマンドプロンプトで実行：

```powershell
cd C:\ai-script\tools\sf6-buckler-export
npm install
npx playwright install chromium
```

## 初期設定

### 自分の SID を確認

1. Buckler のサイトで自分のプロフィールページを開く
2. URL を確認：
   ```
   https://www.streetfighter.com/6/buckler/ja-jp/profile/1146188535/...
                                                           ^^^^^^^^^^
                                                           ここがSID
   ```

### SID をツールに設定

`src\export_buckler_auto.js` をメモ帳などで開いて、18 行目を編集：

```javascript
const SID = "1146188535"; // ←ここを自分のSIDに変更
```

保存して閉じてください。

## 使い方

### 起動

`export.bat` をダブルクリックしてください。

### 初回ログイン

1. ブラウザが自動で開きます
2. Buckler にログインしてください
3. バトルログ（ランクマ）画面が表示されたら、PowerShell ウィンドウに戻って **Enter キー** を押してください

### 自動実行

- 自動で戦績データを取得して保存します
- 2 時間 30 分ごとに自動で繰り返します
- ブラウザは開いたままにしておいてください

### 停止方法

PowerShell ウィンドウをアクティブにして **Ctrl+C** を押してください。

自動的に：

1. 今までの CSV ファイルを統合
2. 重複を削除
3. `battlelog_consolidated.csv` に保存
4. 元のファイルは `archived` フォルダに移動

## 保存場所

### メインの CSV ファイル

```
C:\ai-script\tools\sf6-buckler-export\exported-csv\battlelog_consolidated.csv
```

このファイルを Excel や Google Sheets で開いて分析できます。

### CSV の内容

| 列名            | 内容                                 |
| --------------- | ------------------------------------ |
| battle_time_jst | 対戦日時（日本時間）                 |
| battle_type     | 対戦種別（RANKED MATCH など）        |
| my_character    | 自分のキャラクター                   |
| opp_character   | 相手のキャラクター                   |
| my_mr           | 自分の MR（マスターレート）          |
| opp_mr          | 相手の MR                            |
| result          | 勝敗（WIN/LOSE）                     |
| round_score     | ラウンド結果（配列形式、詳細は下記） |
| replay_id       | リプレイ ID                          |
| page            | 取得元ページ番号                     |

#### round_score の読み方

`round_score` 列には各ラウンドの結果が配列形式で記録されます：

- **正の数字**: 自分が勝ったラウンド

  - `8` = Perfect 勝ち
  - `7` = CA（超必殺技）勝ち
  - `6` = SA（スーパーアート）勝ち
  - `5` = OD（オーバードライブ）勝ち
  - `2` = 削り勝ち
  - `1` = 通常勝ち

- **負の数字**: 自分が負けたラウンド（相手の勝ち方）
  - `-8` = Perfect 負け
  - `-7` = CA で負け
  - `-6` = SA で負け
  - `-5` = OD で負け
  - `-2` = 削られて負け
  - `-1` = 通常負け

**例**:

- `"[8,1]"` → 1R 目 Perfect 勝ち、2R 目通常勝ち（2-0 勝利）
- `"[-2,-8]"` → 1R 目削り負け、2R 目 Perfect 負け（0-2 敗北）
- `"[1,-2,-7]"` → 1R 目通常勝ち、2R 目削り負け、3R 目 CA 負け（1-2 敗北）

### アーカイブ

古い CSV ファイルは `exported-csv\archived\` に 30 日間保存されます。

## よくある質問

### Q: データが取得できない

**A:** ログインが切れている可能性があります。

1. ブラウザウィンドウを確認
2. ログイン画面が表示されていたら、再度ログイン
3. バトルログ画面が表示されたら Enter キーを押す

### Q: ブラウザを閉じてしまった

**A:** プログラムを再起動してください（`export.bat`をダブルクリック）。

### Q: Excel で開くと文字化けする

**A:** Excel の「データ」タブ → 「テキストファイルから」で CSV を開き、文字コードを「UTF-8」に指定してください。

### Q: 2 回目以降はログイン不要？

**A:** はい。セッション情報を保存しているため、通常はログイン不要です。ただし、一定期間経過後や Buckler のメンテナンス後は再ログインが必要になる場合があります。

### Q: 取得間隔を変更したい

**A:** `src\export_buckler_auto.js` の 20 行目を編集：

```javascript
const SCRAPE_INTERVAL = 150; // 分単位（150 = 2時間30分）
```

例：1 時間ごとにするなら `60` に変更

### Q: 統合された CSV が作られない

**A:** Ctrl+C で停止したときに自動作成されます。手動で作成する場合：

```powershell
cd C:\ai-script\tools\sf6-buckler-export
node src\consolidate_csv.js
```

### Q: エラーが出て動かない

**A:** 以下を試してください：

1. Node.js のバージョン確認（v14 以降が必要）
2. Playwright の再インストール：
   ```powershell
   npx playwright install chromium
   ```
3. それでもダメな場合は、一度 `node_modules` フォルダを削除して `npm install` をやり直す

## 設定のカスタマイズ

`src\export_buckler_auto.js` で変更可能な設定：

| 行番号 | 設定項目              | デフォルト値 | 説明                     |
| ------ | --------------------- | ------------ | ------------------------ |
| 18     | `SID`                 | 要変更       | 自分のプレイヤー ID      |
| 19     | `TOTAL_PAGES`         | 10           | 取得するページ数         |
| 20     | `SCRAPE_INTERVAL`     | 150          | 取得間隔（分）           |
| 21     | `KEEP_ALIVE_INTERVAL` | 60           | セッション延命間隔（分） |

## トラブルシューティング

### ツールが途中で止まる

- ネットワーク接続を確認
- ブラウザウィンドウが閉じられていないか確認
- エラーメッセージが表示されている場合は内容を確認

### セッション切れが頻繁に起こる

`KEEP_ALIVE_INTERVAL` を短く設定（例：30 分）してください。

### 容量が足りなくなってきた

アーカイブの保持期間を短くできます：

`src\consolidate_csv.js` の 14 行目を編集：

```javascript
const ARCHIVE_DAYS = 30; // 日数を減らす（例：7）
```
