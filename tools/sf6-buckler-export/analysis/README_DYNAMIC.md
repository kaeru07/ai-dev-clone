# 動的分析レポートの使い方

## 📊 概要

`analysis_report_dynamic.html` は、`battlelog_consolidated.csv` を動的に読み込んで分析する HTML ファイルです。
CSV が更新されるたびにスクリプトを実行する必要はなく、ブラウザをリロードするだけで最新データが表示されます。

## 🚀 使い方

### 方法 1: ローカルサーバーを使用（推奨）

ブラウザの CORS 制限を回避するため、ローカルサーバーを起動して使用します。

#### Windows（バッチファイル）

```batch
start_server.bat
```

#### Windows（PowerShell）

```powershell
.\start_server.ps1
```

サーバーが起動すると、自動的にブラウザで `http://localhost:8000/` が開きます。
メニューから「動的レポート」を選択してください。

### 方法 2: ブラウザで直接開く

一部のブラウザでは直接 HTML ファイルを開いても動作する場合がありますが、
CORS 制限により動作しないことがあります。

動作しない場合は**方法 1**を使用してください。

## 🔄 データの更新

1. `battlelog_consolidated.csv` が更新されたら
2. ブラウザで以下のいずれかを実行：
   - **F5 キー**を押してページをリロード
   - **「データを再読み込み」ボタン**をクリック

## 📌 注意事項

- **Python 3.x** がインストールされている必要があります
- サーバーを停止するには `Ctrl+C` を押してください
- サーバー起動中はターミナルを閉じないでください

## 🛠️ トラブルシューティング

### エラー: データの読み込みに失敗しました

**原因**: ブラウザの CORS 制限によりローカルファイルを読み込めない

**解決策**: `start_server.bat` または `start_server.ps1` を使用してローカルサーバーを起動してください

### エラー: Python が見つかりません

**解決策**: Python 3.x をインストールしてください

- https://www.python.org/downloads/

または、Node.js がある場合：

```bash
npx http-server -p 8000
```

### ポート 8000 が既に使用されている

`start_server.bat` / `start_server.ps1` を編集して、別のポート番号（例: 8080）に変更してください：

```batch
python -m http.server 8080
```

## 💡 メリット

✅ CSV が更新されるたびにスクリプトを実行する必要がない
✅ ブラウザをリロードするだけで最新データを表示
✅ Node.js や npm install が不要（Python のみ）
✅ リアルタイムで分析結果を確認できる
