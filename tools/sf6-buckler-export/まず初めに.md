# まず初めに - セットアップガイド

このツールを使用する前に、以下の 3 つのソフトウェアをインストールする必要があります。

---

## 📋 必要なもの

1. **Node.js** - JavaScript ランタイム（スクレイピングスクリプトの実行に必要）
2. **Playwright** - ブラウザ自動操作ライブラリ（Node.js 経由でインストール）
3. **Python 3.x** - 分析サーバーの実行に必要

---

## 1️⃣ Node.js のインストール

### 手順

1. **公式サイトからダウンロード**

   - ブラウザで以下の URL を開く：https://nodejs.org/
   - 「LTS（推奨版）」の緑色のボタンをクリック
   - `node-v20.x.x-x64.msi` のようなファイルがダウンロードされます

2. **インストーラーを実行**

   - ダウンロードした MSI ファイルをダブルクリック
   - 「Next」を押していけば OK
   - **重要**: 「Add to PATH」にチェックが入っていることを確認（デフォルトで入っています）

3. **インストール確認**
   - インストール完了後、PowerShell またはコマンドプロンプトを開く
   - 以下のコマンドを実行：
   ```powershell
   node --version
   ```
   - バージョン番号（例: `v20.11.0`）が表示されれば OK

> **注意**: インストール後、開いていたターミナルは一度閉じて、新しく開き直してください。

---

## 2️⃣ Playwright のインストール

### 前提条件

- Node.js がインストールされていること

### 手順

1. **このフォルダで PowerShell を開く**

   - エクスプローラーで `sf6-buckler-export` フォルダを開く
   - アドレスバーに `powershell` と入力して Enter

2. **npm パッケージをインストール**

   ```powershell
   npm install
   ```

   - `node_modules` フォルダが作成され、必要なパッケージがインストールされます

3. **Playwright ブラウザをインストール**

   ```powershell
   npx playwright install chromium
   ```

   - Chromium ブラウザがダウンロード＆インストールされます（数分かかります）

4. **インストール確認**
   ```powershell
   npx playwright --version
   ```
   - バージョン番号が表示されれば OK

---

## 3️⃣ Python のインストール

### 手順

1. **公式サイトからダウンロード**

   - ブラウザで以下の URL を開く：https://www.python.org/
   - 「Downloads」→「Windows」
   - 「Python 3.12.x」のようなバージョンをダウンロード

2. **インストーラーを実行**

   - ダウンロードした EXE ファイルをダブルクリック
   - **重要**: 最初の画面で「**Add Python to PATH**」に必ずチェックを入れる ✅
   - 「Install Now」をクリック

3. **インストール確認**
   - PowerShell またはコマンドプロンプトを開く
   - 以下のコマンドを実行：
   ```powershell
   python --version
   ```
   - バージョン番号（例: `Python 3.12.1`）が表示されれば OK

> **注意**: インストール後、開いていたターミナルは一度閉じて、新しく開き直してください。

---

## ✅ セットアップ完了の確認

すべてのソフトウェアがインストールできたか、以下のコマンドで確認できます：

```powershell
node --version
python --version
npx playwright --version
```

すべてでバージョン番号が表示されれば、セットアップ完了です！

## ❓ トラブルシューティング

### Node.js / Python のコマンドが認識されない

**症状**: `node --version` や `python --version` で「コマンドが見つかりません」と表示される

**解決方法**:

1. ターミナルを一度閉じて、新しく開き直す
2. それでもダメな場合、PC を再起動
3. まだダメな場合、Node.js / Python を再インストールし、「Add to PATH」のチェックを確認

### npm install でエラーが出る

**症状**: `npm install` 実行時にエラーが表示される

**解決方法**:

1. Node.js が正しくインストールされているか確認：`node --version`
2. フォルダの場所が正しいか確認（`sf6-buckler-export` フォルダで実行）
3. インターネット接続を確認

### Playwright のインストールが途中で止まる

**症状**: `npx playwright install chromium` が進まない

**解決方法**:

1. インターネット接続を確認（ブラウザのダウンロードに数百 MB かかります）
2. 時間がかかっている場合は、5〜10 分待ってみる
3. Ctrl+C で中断し、再度実行してみる

## 📝 補足

- **インストール容量**: Node.js（約 200MB）、Playwright（約 300MB）、Python（約 100MB）
- **インストール時間**: 各 5〜10 分程度（インターネット速度による）
- **管理者権限**: インストール時に管理者権限を求められる場合があります
